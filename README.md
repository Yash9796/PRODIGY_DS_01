# PRODIGY_DS_01 – Data Visualization using Bar Chart and Histogram

## 📌 Objective
The objective of this task is to create visual representations of data using a bar chart and histogram to analyze the distribution of categorical and continuous variables such as gender distribution and age distribution in a population.

## 🛠 Tools & Technologies Used
- Python
- Pandas
- Matplotlib

## 📊 Project Description
In this project, I performed data visualization to understand how data is distributed across categories and numerical ranges.

- A Bar Chart was created to visualize categorical data (e.g., Gender distribution).
- A Histogram was used to represent the frequency distribution of a continuous variable (e.g., Age distribution).

## 📈 Steps Performed
1. Imported dataset using Pandas
2. Cleaned and prepared the data
3. Used Matplotlib to create:
   - Bar chart for categorical variable
   - Histogram for continuous variable
4. Analyzed the graphical output

## 📊 Key Insights
- The bar chart clearly shows the count comparison between categories.
- The histogram helps in understanding how ages are distributed across intervals.
- Visualization makes data interpretation easier and more effective.

## 🎯 Learning Outcomes
- Understanding the difference between bar charts and histograms
- Hands-on practice with Matplotlib
- Improved data visualization and interpretation skills
- Learned how graphical representation simplifies complex datasets

## 📌 Conclusion
Data visualization is a crucial step in data analysis. Through this task, I gained practical experience in representing both categorical and continuous data distributions effectively using Python.
